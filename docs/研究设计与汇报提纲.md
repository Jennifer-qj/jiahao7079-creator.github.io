# 《牡丹亭》格律形式与“至情”表达：研究设计

## 一、核心问题

格律形式如何参与《牡丹亭》的“至情”表达？

这里的“参与”不是把某一种平仄或句式机械对应某一种情绪，而是观察形式怎样组织情感发生的时间过程：怎样铺陈、受阻、转折与收束。

## 二、材料与方法

主研究集为 8 个关键场景中的 80 支人工核验曲词：惊梦、寻梦、写真、闹殇、拾画、回生、婚走、圆驾。每支曲保留平仄序列、韵脚、换韵次数、句长序列、人工“形式—情感”解释和已有的词汇情感向量。

程序派生五类描述性指标：

1. 仄声比：观察声调压力。
2. 平仄交替率：观察节奏起伏。
3. 平仄最长连续段：观察声调阻滞或延续。
4. 句长变异系数：观察句式伸缩。
5. 换韵次数：观察语势和心理转折。

智能体采用“任务判断—工具调用—证据综合—出处返回”的流程，可调用曲牌度量检索、场景比较、原文片段检索和人物关系查询。模型只负责在已检索证据上综合，不代替原始标注和研究判断。

## 三、目前最有价值的发现

### 1. 单指标不能直接等同于情感

在同时具有词汇情感向量的 60 支曲中，四类主要形式指标与正、负情感总量的全局线性相关都很弱，绝对值不超过 0.16。这说明“仄声多就是悲”“换韵多就是情绪强”一类简单映射站不住脚。

### 2. 形式更像情感的组织机制

- 句式伸缩形成“铺陈—骤收”的时间结构。
- 平仄密度与交替调节急迫、阻滞与回旋。
- 韵脚变化常与心理转向、场景转换或语势收束协同。

因此，形式与情感的关系应在“曲牌—场景—叙事位置”三级语境中解释。

### 3. 值得优先细读的曲牌

按句长变异系数排序，较突出的曲牌包括：

- 回生【字字双】0.649
- 闹殇【尾声】0.606
- 拾画【尾声】0.585
- 惊梦【尾声】0.493
- 寻梦【懒画眉】0.485

它们不是“最动情”的排名，而是形式伸缩最明显、最值得回到原文重读的入口。

## 四、两分钟汇报结构

1. 20 秒：提出问题——格律不只是外壳，是否参与了“至情”的生成？
2. 30 秒：说明材料——80 支人工核验曲词、55 出原文和四类 Agent 工具。
3. 45 秒：展示发现——全局弱相关反驳机械对应；句式、平仄、韵脚在具体场景中组织情感。
4. 20 秒：现场演示——点击一支曲牌，再让智能体返回形式解释与原文出处。
5. 5 秒：收束——人文判断在前，模型综合在后。

## 五、研究边界

- 当前是描述性分析与计算辅助细读，不能直接推出历史因果。
- 词汇情感向量存在缺失，相关分析只使用 60 支有值曲词。
- 原文底本的准确书目信息仍需在正式文本中补核。
- 人工标注是核心证据，程序派生指标和模型回答均可追溯、可复查。

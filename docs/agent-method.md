# “曲情问答”智能体方法说明

## 为什么不直接微调

现有材料以 80 支人工核验曲词、55 出原文、实体标注和 178 条关系事件为核心，规模适合检索增强与结构化工具调用，不足以支撑可靠的领域预训练。结项成果不声称已经微调模型，而是把性能提升落实为四个可核验环节：

1. 把人工标注转换为人物、原文、格律、场景和关系五类工具；
2. 由大模型根据问题选择工具，而不是固定关键词模板；
3. 要求最终回答区分文本事实、计算观察和研究解释，并引用工具返回的证据编号；
4. 使用固定问题集比较旧版、本地兜底与 API 智能体的正确性、证据覆盖和边界意识。

## 回答链路

用户问题 → 模型判断任务 → 调用 1–4 个研究工具 → 工具返回结构化数据与证据编号 → 模型综合回答 → 页面展示答案、工具轨迹和出处。

## 评测维度

- 基础事实正确：人物与情节不得答非所问。
- 数据落地：涉及项目数据的问题至少调用一个研究工具。
- 引证完整：重要判断能够回到曲词、原文或关系事件。
- 解释分层：区分“数据中有什么”和“研究者如何解释”。
- 边界意识：不把描述性相关直接写成因果。
- 多轮一致：追问能够沿用上一轮已经确定的人物、场景或曲牌。

# 曲情证｜《牡丹亭》格律与“至情”研究智能体

这是一个可直接汇报、可继续编辑的数字人文网页成果。主研究问题是：

> 格律形式如何参与《牡丹亭》的“至情”表达？

## 已实现

- 80 支人工核验曲词的形式指标与场景比较
- 平仄、句长、韵脚、人工“形式—情感”解释的曲牌级细读
- 55 出原文的检索增强生成（RAG）
- 曲牌度量、场景比较、原文检索、人物关系查询四类 Agent 工具
- 无 API Key 也能运行的本地证据综合；配置兼容接口后自动启用大模型综合
- 杜丽娘情感历程与人物关系两组补充视图
- 四屏、可键盘控制的两分钟汇报模式
- 桌面端和手机端自适应

## 本地运行

```powershell
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:3000`。

## 可选的大模型配置

复制 `.env.example` 为 `.env.local`，填写：

- `LLM_API_KEY`
- `LLM_BASE_URL`
- `LLM_MODEL`

接口须兼容 `POST /chat/completions`。未配置时，系统会使用确定性的证据综合模式，不影响检索、引用与现场演示。

## 数据来源与边界

- 工作簿中的曲词格律、形式—情感解释、实体和关系数据以人工标注为主。
- 词汇情感趋势沿用原表注明的“历史人文大数据平台”结果。
- 原文来自用户提供 Word；据用户说明，底本为国家图书馆藏《牡丹亭还魂记》，具体版本书目信息仍待核验。
- 本项目做描述性探索与计算辅助细读，不把相关性直接解释成因果。

# 曲情证｜《牡丹亭》格律与“至情”研究智能体

[打开公开网站](https://jennifer-qj.github.io/jiahao7079-creator.github.io/)

这是一个可直接汇报、可继续编辑的数字人文网页成果。主研究问题是：

> 格律形式如何参与《牡丹亭》的“至情”表达？

## 已实现

- 80 支人工核验曲词的形式指标与场景比较
- 平仄、句长、韵脚、人工“形式—情感”解释的曲牌级细读
- 55 出原文的检索增强生成（RAG）
- 人物档案、曲牌度量、场景比较、原文检索、人物关系事件五类 Agent 工具
- DeepSeek V4 Flash 负责推理与工具选择；浏览器端证据综合作为断网降级方案
- 杜丽娘情感历程与人物关系两组补充视图
- 四屏、可键盘控制的两分钟汇报模式
- 桌面端和手机端自适应

## 本地运行

```powershell
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:3000`。

## 智能体运行方式

线上智能体采用“DeepSeek V4 Flash + 研究工具 + RAG + 提示词工程 + 问题集评测”。模型先判断问题，再调用本项目的人物档案、曲牌度量、场景比较、原文检索或关系事件工具，最后生成带出处和证据边界的回答。网站未声称经过微调或预训练；其相对通用聊天模型的改进来自经过约束的领域数据、工具调用流程和评测。

API Key 只以 Cloudflare Worker 的加密 Secret 保存，不进入网页代码或 GitHub 仓库。免费 Worker 还负责限制问题长度、输出长度、工具轮次与访问频率。若后端不可用，网页会回退到本地证据综合，保证现场仍可演示。

## 数据来源与边界

- 工作簿中的曲词格律、形式—情感解释、实体和关系数据以人工标注为主。
- 词汇情感趋势沿用原表注明的“历史人文大数据平台”结果。
- 原文来自用户提供 Word；据用户说明，底本为国家图书馆藏《牡丹亭还魂记》，具体版本书目信息仍待核验。
- 本项目做描述性探索与计算辅助细读，不把相关性直接解释成因果。
